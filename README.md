# 📖 Whispers of Earth and Ether - Digital Poetry Book

A minimal, immersive digital experience that blends poetry with ambient visuals and interactive transitions. This project explores three existential dimensions: **The Forest (Nature)**, **The Space (Cosmos)**, and **The Time (Existence)**.

## ✨ Features

- **Immersive Visuals**: Dynamic background images that transition smoothly between themes.
- **Interactive Elements**: Text-highlighting effects on click and ambient particles that react to the atmosphere.
- **Adaptive Design**: Fully responsive layout that works on mobile and desktop.
- **Cinematic Transitions**: Fade-and-slide animations for a seamless reading experience.

## 🚀 Deployment Guide

Since this is a static HTML project, you can host it for free using several platforms.

### Option 1: GitHub Pages (Recommended)
1. Create a new repository on GitHub.
2. Upload the `index.html` file to the root of the repository.
3. Go to **Settings** $\rightarrow$ **Pages**.
4. Under **Build and deployment**, set the source to `Deploy from a branch` and select `main`.
5. Save. Your site will be live at `https://your-username.github.io/your-repo-name/`.

### Option 2: Vercel / Netlify (Fastest)
1. Drag and drop the folder containing `index.html` into the [Vercel](https://vercel.com) or [Netlify](https://netlify.com) dashboard.
2. They will automatically provide you with a live URL (e.g., `poetry-book.vercel.app`).

## 🛠️ Local Setup

If you want to run this locally:
1. Clone the repository.
2. Open `index.html` in any modern web browser.

## 🎨 Tech Stack
- **HTML5 & CSS3**: For structure and cinematic styling.
- **JavaScript**: For the interactive navigation and particle system.
- **Google Fonts**: Playfair Display, Lora, and Inter for a professional typographic feel.
- **Unsplash API**: For high-quality thematic imagery.
